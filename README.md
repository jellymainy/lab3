# Lab3TP

**Проект:** Анализ социально-экономической статистики России  
**Варианты:** №7, №9, №15  
**Технологии:** Python 3, Pandas, Matplotlib, CSV  
**Тип приложения:** консольное приложение с визуализацией графиков  
**Предметная область:** статистический анализ и прогнозирование данных методом скользящей средней

---

## Описание проекта

Lab3TP — это командный проект по дисциплине «Технологии программирования», посвящённый изучению систем контроля версий Git и организации совместной разработки.

Приложение позволяет анализировать различные статистические данные России за последние годы, строить графики, выполнять прогнозирование методом скользящей средней и отображать результаты в удобном формате.

В проекте реализованы три независимых аналитических модуля:

1. **Анализ браков и разводов** (вариант №7)
2. **Анализ рынка первичного жилья** (вариант №9)
3. **Анализ инфекционных заболеваний** (вариант №15)

Каждый модуль:
- загружает данные из CSV-файлов;
- выводит таблицу с исходной статистикой;
- выполняет аналитические вычисления;
- строит графики;
- выполняет прогнозирование методом скользящей средней.

Проект разработан с использованием Git-flow подхода:
- отдельные ветки для каждого участника;
- ветка `dev` для объединения функциональности;
- pull request и code review;
- последующее слияние в `main`.

# Основные возможности

## 1. Модуль анализа браков и разводов (Вариант №7)

### Возможности:
- Загрузка статистики о браках и разводах в России;
- Отображение данных в табличном формате;
- Построение графиков:
  - количества браков;
  - количества разводов;
- Определение:
  - возраста, в котором мужчины чаще женились;
  - возраста, в котором женщины чаще выходили замуж;
  - возраста, в котором мужчины чаще разводились;
  - возраста, в котором женщины чаще разводились;
- Прогнозирование статистики на несколько лет вперёд методом скользящей средней.

### Используемые данные:
CSV-файл `marriages.csv` содержит:
- год;
- количество браков;
- количество разводов;
- возрастные показатели.

### Визуализация:
- линейные графики;
- отображение фактических и прогнозируемых данных;
- прогноз выделяется пунктирной линией.

## 2. Модуль анализа рынка жилья (Вариант №9)

### Возможности:
- Загрузка данных о ценах на первичное жильё;
- Отображение статистики по стоимости квартир;
- Построение графиков изменения цен;
- Анализ:
  - какие квартиры подорожали сильнее всего;
  - какие квартиры изменились минимально;
- Прогнозирование стоимости жилья методом скользящей средней.

### Анализируемые категории:
- студии;
- однокомнатные квартиры;
- двухкомнатные квартиры;
- трёхкомнатные квартиры.

### Используемые данные:
CSV-файл `housing.csv` содержит:
- год;
- стоимость квадратного метра;
- категории квартир.

### Визуализация:
- отдельные линии для каждого типа жилья;
- прогноз отображается пунктирной линией;
- поддерживается масштабирование графиков средствами Matplotlib.

---

## 3. Модуль анализа инфекционных заболеваний (Вариант №15)

### Возможности:
- Загрузка статистики по инфекционным заболеваниям;
- Отображение данных в табличном формате;
- Построение графиков заболеваемости;
- Определение:
  - заболевание с максимальным снижением заболеваемости;
  - заболевание с минимальным снижением заболеваемости;
- Прогнозирование дальнейшей динамики методом скользящей средней.

### Анализируемые заболевания:
- туберкулёз;
- ВИЧ;
- корь;
- грипп;
- гепатит B.

### Используемые данные:
CSV-файл `diseases.csv` содержит:
- год;
- количество зарегистрированных случаев заболеваний.

### Визуализация:
- многолинейные графики;
- отдельная линия для каждой инфекции;
- отображение прогнозируемых значений.

# Метод прогнозирования

Во всех модулях используется метод **экстраполяции по скользящей средней**.

Суть метода:
- берётся несколько последних значений временного ряда;
- вычисляется их среднее значение;
- результат используется как прогноз следующего периода;
- далее прогнозируемое значение включается в расчёт последующих прогнозов.

Прогнозирование реализовано в отдельном сервисе:

```python
moving_average_forecast(values, window, steps)
```
